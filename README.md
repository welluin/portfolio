## О проекте

Цель проекта — создать удобную площадку для представления разработчика, его работ и профессиональных интересов.

При разработке особое внимание уделено организации компонентов, визуальной структуре страницы и адаптации интерфейса под различные размеры экрана.

Проект также служит практическим примером применения React и современных инструментов frontend-разработки.

## Возможности

- **Главный экран** — представление разработчика и основных направлений деятельности.
- **Навигация** — переход между разделами сайта.
- **Услуги** — описание направлений работы в области программирования и разработки интерфейсов.
- **Процесс разработки** — представление основных этапов выполнения задач.
- **Портфолио** — раздел для демонстрации проектов.
- **Статистика** — отдельный блок с показателями.
- **Контакты** — раздел с информацией для связи.
- **Адаптивная вёрстка** — настройка интерфейса для разных размеров экрана.
- **Компонентная организация** — разделение страницы на отдельные React-компоненты для упрощения сопровождения кода.

## Архитектура проекта

Проект использует **компонентный подход React**: интерфейс разделён на независимые компоненты, каждый из которых отвечает за определённый раздел страницы.

### Схема взаимодействия компонентов

```text
main.jsx
   │
   ▼
 App.jsx
   │
   ├── Header.jsx
   ├── Hero.jsx
   ├── Stats.jsx
   ├── Services.jsx
   ├── Process.jsx
   ├── Portfolio.jsx
   ├── Contact.jsx
   └── Footer.jsx
```

`main.jsx` служит точкой входа приложения и запускает React. Компонент `App.jsx` объединяет основные части интерфейса, формируя страницу портфолио.

Компоненты из каталога `src/components/` разделяют интерфейс на логические блоки. Такой подход упрощает чтение кода, изменение отдельных разделов и добавление новых возможностей.

### Основные принципы

- **Компонентность:** интерфейс разделён на небольшие логические части.
- **Разделение ответственности:** каждый компонент отвечает за отдельный участок страницы.
- **Модульность:** изменения в одном компоненте обычно не требуют переписывать всю страницу.
- **Разделение разметки и оформления:** JSX описывает структуру интерфейса, а CSS отвечает за внешний вид.
- **Расширяемость:** новые разделы можно добавлять по мере развития проекта.

### Организация стилей

- `App.css` — стили оформления приложения.
- `index.css` — глобальные стили и общие правила оформления.

## Требования

Для работы с проектом необходимы:

- [Node.js](https://nodejs.org/) — среда выполнения JavaScript и пакетный менеджер npm.
- [Git](https://git-scm.com/) — система контроля версий.

Для редактирования исходного кода можно использовать [Visual Studio Code](https://code.visualstudio.com/) или другой редактор.

## Установка и запуск

### 1. Клонирование репозитория

Открой терминал и выполни:

```bash
git clone https://github.com/welluin/portfolio.git
```

### 2. Переход в каталог проекта

```bash
cd portfolio
```

### 3. Установка зависимостей

```bash
npm install
```

Команда устанавливает зависимости, необходимые для запуска и сборки приложения.

### 4. Запуск сервера разработки

```bash
npm run dev
```

Если PowerShell в Windows блокирует выполнение команды, используй:

```powershell
npm.cmd run dev
```

После запуска Vite выведет в терминале локальный адрес сайта. Обычно это:

`http://localhost:5173/`

Открой указанный адрес в браузере, чтобы посмотреть приложение.

Во время работы сервера изменения в исходном коде обычно отображаются в браузере автоматически.

## Сборка проекта

Для создания production-сборки выполните:

```bash
npm run build
```

Vite создаст готовые файлы приложения в каталоге `dist/`.
