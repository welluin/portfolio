# Портфолио разработчика

Персональный сайт-портфолио, созданный для представления проектов, навыков и подхода к разработке программного обеспечения.

Проект демонстрирует навыки работы с frontend-разработкой, программированием, базами данных и сопровождением программных решений. Сайт имеет минималистичный дизайн, адаптивную вёрстку и структурированное представление информации.

## О проекте

Цель проекта — создать удобную площадку для презентации разработчика, его работ и профессиональных навыков.

Сайт включает следующие разделы:

- **Главный экран** — краткое представление разработчика и основных направлений работы.
- **Услуги** — описание направлений деятельности: разработка интерфейсов, программирование, работа с базами данных и сопровождение программного обеспечения.
- **Подход к разработке** — основные этапы работы над задачей: анализ, планирование, реализация и проверка результата.
- **Портфолио** — раздел для демонстрации проектов и перехода к их исходному коду.
- **Контакты** — информация для связи.

## Используемые технологии

- **React** — создание пользовательского интерфейса из переиспользуемых компонентов.
- **JavaScript** — реализация логики и интерактивных элементов.
- **Vite** — запуск сервера разработки и сборка проекта.
- **HTML5** — структурирование содержимого страниц.
- **CSS3** — оформление интерфейса, создание макета и адаптивной вёрстки.
- **Git и GitHub** — управление версиями и хранение исходного кода.

## Требования

Перед запуском проекта необходимо установить:

- [Node.js](https://nodejs.org/) — среду выполнения JavaScript и пакетный менеджер npm.
- [Git](https://git-scm.com/) — систему контроля версий.
- Редактор кода, например [Visual Studio Code](https://code.visualstudio.com/).

## Установка и запуск

### 1. Клонирование репозитория

Откройте терминал и выполните команду:

```bash
git clone https://github.com/welluin/portfolio
```

### 2. Переход в папку проекта

```bash
cd portfolio
```

Если папка проекта называется иначе, укажите её фактическое название.

### 3. Установка зависимостей

```bash
npm install
```

Команда устанавливает библиотеки, необходимые для работы проекта.

### 4. Запуск сервера разработки

```bash
npm run dev
```

Если PowerShell в Windows блокирует выполнение команды, используйте:

```powershell
npm.cmd run dev
```

После запуска терминал покажет локальный адрес сайта. Обычно это:

`http://localhost:5173/`

Откройте указанный адрес в браузере, чтобы посмотреть сайт.

### 5. Сборка проекта

Для создания готовой версии сайта выполните:

```bash
npm run build
```

Собранные файлы будут помещены в папку `dist`.

Для локальной проверки готовой сборки можно выполнить:

```bash
npm run preview
```

## Основные возможности

- Представление разработчика и его направлений деятельности.
- Демонстрация проектов в виде отдельных карточек.
- Переход к исходному коду проектов на GitHub.
- Навигация между разделами сайта.
- Адаптация интерфейса под разные размеры экрана.
- Компонентная организация кода для удобства сопровождения и развития проекта.

## Развитие проекта

В дальнейшем проект можно расширить следующими возможностями:

- Добавить реальные проекты с описанием задач, используемых технологий и результатов.
- Реализовать фильтрацию проектов по категориям.
- Добавить отдельные страницы с подробным описанием работ.
- Улучшить доступность и производительность сайта.
- Разместить сайт на хостинге и добавить публичную ссылку на портфолио.
